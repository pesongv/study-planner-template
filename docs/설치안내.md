# 우리 반 독서실 — 설치 안내서 (선생님용)

명령어 없이 **웹 화면에서 클릭만으로** 우리 반 전용 독서실을 만드는 방법이에요.
모두 **무료**이고, 처음 하면 30분쯤 걸려요.

> 💡 막히면 이 문서를 통째로 **Claude나 ChatGPT에 붙여 넣고** "지금 ○단계인데 화면에 △△가 떠요"라고 물어보세요.
> 화면 캡처를 같이 보여 주면 더 정확하게 도와줘요.

---

## 준비물
- **구글 계정** — 개인 Gmail 추천 (학교 계정은 관리자가 막아 둔 경우가 많아요)
- **GitHub 계정** — 없으면 https://github.com 에서 무료 가입
- 학생 명단 (학번, 이름)

만드는 동안 아래 표의 **값 5개**를 모으게 돼요. 메모장을 하나 열어 두세요.

| 이름 | 어디서 나오나 |
|---|---|
| `GOOGLE_SHEET_ID` | 1단계 |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | 2단계 |
| `GOOGLE_PRIVATE_KEY` | 2단계 |
| `JWT_SECRET` | 4단계에서 직접 만들기 |
| `TEACHER_INIT_PASSWORD` | 4단계에서 직접 정하기 |

---

## 1단계. 구글 시트 만들기 (2분)
1. https://sheets.new 에 들어가면 빈 시트가 열려요.
2. 왼쪽 위 제목을 `우리반 독서실 DB` 처럼 바꿔요.
3. 주소창의 주소에서 `/d/` 와 `/edit` 사이 글자를 복사해 메모장에 적어요. 이게 **`GOOGLE_SHEET_ID`** 예요.
   ```
   https://docs.google.com/spreadsheets/d/【여기 긴 글자】/edit
   ```
4. 시트 안에는 아무것도 쓰지 마세요. 탭과 제목줄은 나중에 앱이 알아서 만들어요.

## 2단계. 구글 클라우드에서 "로봇 계정" 만들기 (15분)
앱이 시트에 글을 쓸 때 쓰는 계정이에요.

1. https://console.cloud.google.com 에 같은 구글 계정으로 들어가요.
   - "액세스 차단됨 / 2단계 인증" 이 뜨면 → 구글 계정에 **2단계 인증을 켜고** 몇 분 뒤 새로고침 (무료)
   - "$300 무료 체험" 같은 안내는 **무시** — 카드 등록 필요 없어요
2. 왼쪽 위 **프로젝트 선택 → 새 프로젝트** → 이름 `study-planner` → **만들기** → 만든 프로젝트를 선택
3. 위쪽 검색창에 `Google Sheets API` → 들어가서 **사용** 버튼
4. 검색창에 `서비스 계정` → **IAM 및 관리자 › 서비스 계정** → **+ 서비스 계정 만들기**
   - 이름 `sheets-bot` → **만들고 계속하기** → 권한은 비워 두고 **완료**
5. 목록에 생긴 `sheets-bot@....iam.gserviceaccount.com` 이메일을 눌러요
   → 위쪽 **키** 탭 → **키 추가 › 새 키 만들기 › JSON › 만들기** → `.json` 파일이 다운로드돼요
6. 받은 `.json` 파일을 **텍스트 편집기(맥) / 메모장(윈도우)** 로 열어요. 아래 두 줄의 **따옴표 안 내용**을 메모장에 복사해요.
   ```
   "client_email": "【이게 GOOGLE_SERVICE_ACCOUNT_EMAIL】",
   "private_key": "【이게 GOOGLE_PRIVATE_KEY — -----BEGIN 부터 END PRIVATE KEY-----\n 까지 전부】",
   ```
   ⚠️ 이 파일은 시트를 고칠 수 있는 열쇠예요. 카톡·메일·게시판에 올리지 마세요. 설치가 끝나면 지워도 돼요.

## 3단계. 시트를 로봇에게 공유 (2분)
1. 1단계의 시트에서 오른쪽 위 **공유**
2. 2단계의 `sheets-bot@...` 이메일을 붙여 넣고 → 권한 **편집자** → **이메일 알림 보내기 체크 해제** → 공유
3. 아래 "일반 액세스" 는 **제한됨** 그대로 (링크가 있는 모든 사용자 ❌ — 학생 개인정보가 들어가요)

## 4단계. 배포 버튼 누르기 (5분)
1. 이 저장소의 README 에 있는 **[Deploy with Vercel]** 버튼을 눌러요.
2. **Continue with GitHub** 로 Vercel 에 가입/로그인 (무료 **Hobby** 요금제 — Pro·Trial 버튼은 누르지 마세요)
   - 2단계 인증(2FA) 안내가 뜨면: 원하면 설정, 아니면 **Remind Me Later**
3. 저장소 이름은 그대로 두고 **Create** → 이어서 **값 5개**를 넣는 칸이 나와요:
   - `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`, `GOOGLE_SHEET_ID` → 메모장에서 붙여 넣기
   - `JWT_SECRET` → 영어·숫자를 **아무렇게나 40자 이상** 섞어서 (예: 키보드를 마구 두드리기). 아무에게도 알려 주지 마세요
   - `TEACHER_INIT_PASSWORD` → 처음 선생님 로그인에 쓸 비밀번호 (한 번만 써요)
4. **Deploy** → 1~2분 뒤 🎉 화면이 나오면 **Continue to Dashboard** → 위쪽 **Domains** 에 있는 `○○.vercel.app` 이 우리 반 주소예요.

## 5단계. 첫 로그인 (3분)
1. 우리 반 주소로 들어가서 학번 칸에 `teacher`, 비밀번호에 `TEACHER_INIT_PASSWORD` 를 넣어요.
   → 이때 앱이 **시트에 탭 9개와 제목줄을 자동으로 만들어요** (첫 로그인이 몇 초 걸릴 수 있어요)
2. 새 선생님 비밀번호로 바꾸면 **선생님 화면**이 나와요.
3. (선택) 안전을 위해 Vercel › 프로젝트 › **Settings › Environment Variables** 에서 `TEACHER_INIT_PASSWORD` 를 지워요.

## 6단계. 학생 등록 (5분)
1. 엑셀에서 `학번,이름` 두 칸으로 명단을 만들고 **CSV 로 저장** (첫 줄 제목은 있어도 괜찮아요)
2. 선생님 화면 › **CSV 파일 선택** → 등록 끝. 자리 번호는 학번 순서로 자동 배정돼요.
3. 학생들의 첫 비밀번호는 모두 **`000000`** 이에요.
   → **첫 로그인은 교실에서 다 같이** 하고, 그 자리에서 각자 비밀번호를 바꾸게 해 주세요.
   (선생님 화면에서 "아직 안 바꿈" 인 학생은 친구가 대신 들어갈 수 있어요)

## 7단계. 학생들 폰에 앱처럼 추가
- 아이폰(사파리): 아래 **공유 버튼 → 홈 화면에 추가**
- 삼성 인터넷: 아래 **☰ → 현재 페이지 추가 → 홈 화면**
- 크롬: 오른쪽 위 **⋮ → 홈 화면에 추가**

## 자주 막히는 곳
| 증상 | 해결 |
|---|---|
| 첫 로그인에서 "학번 또는 비밀번호가 맞지 않아요" | 학번 칸이 정확히 `teacher` 인지, 비밀번호가 `TEACHER_INIT_PASSWORD` 와 같은지 확인 |
| 첫 로그인에서 "잠시 문제가 생겼어요" | ① 3단계 공유(편집자)를 했는지 ② `GOOGLE_SHEET_ID` 가 맞는지 ③ `GOOGLE_PRIVATE_KEY` 를 BEGIN~END 까지 다 넣었는지. 고친 뒤 Vercel › Deployments › 맨 위 › **Redeploy** |
| 값을 잘못 넣었어요 | Vercel › Settings › Environment Variables 에서 고치고 **Redeploy** |
| 비밀번호를 잊은 학생 | 선생님 화면 › 그 학생 **초기화** → 다시 `000000` |
| 선생님 비밀번호를 잊었어요 | 시트 `학생` 탭에서 `teacher` 줄을 지우고, Vercel 에 `TEACHER_INIT_PASSWORD` 를 다시 넣고 Redeploy → 5단계 다시 |

## 개인정보 안내
- 학생 데이터(학번·이름·공부 기록)는 **선생님 구글 시트에만** 저장돼요. 다른 반·제작자에게 전달되지 않아요.
- 학교 개인정보 담당 선생님께 한 번 확인받고, 학부모 안내문에 "학번과 이름만 사용, 학급 학습관리용" 정도를 적어 두면 좋아요.
