# 우리 반 독서실 — 설치 안내서 (선생님용)

명령어 없이 **웹 화면에서 클릭만으로** 우리 반 전용 독서실을 만드는 방법이에요.
모두 **무료**이고, 처음 하면 20분쯤 걸려요.

> 💡 막히면 이 문서를 통째로 **Claude나 ChatGPT에 붙여 넣고** "지금 ○단계인데 화면에 △△가 떠요"라고 물어보세요.
> 화면 캡처를 같이 보여 주면 더 정확하게 도와줘요. (단, **비밀 키는 AI 채팅에도 붙여 넣지 마세요**)

---

## 준비물
- **GitHub 계정** — 없으면 https://github.com 에서 무료 가입
- 학생 명단 (학번, 이름)

만드는 동안 아래 **값 4개**를 모으게 돼요.

| 이름 | 어디서 나오나 |
|---|---|
| `SUPABASE_URL` | 3단계 |
| `SUPABASE_SECRET_KEY` | 3단계 (비밀!) |
| `JWT_SECRET` | 4단계에서 직접 만들기 (비밀!) |
| `TEACHER_INIT_PASSWORD` | 4단계에서 직접 정하기 |

---

## 1단계. 수파베이스 프로젝트 만들기 (5분)
데이터(학생 명단, 공부 기록)를 저장할 곳이에요.

1. https://supabase.com 에서 **Start your project → Continue with GitHub** 로 가입/로그인
2. **New project** (조직이 없으면 먼저 Personal / **Free** 로 만들기)
   - Project name: `study-planner`
   - Database Password: **Generate a password** (앱에서는 안 써요. 따로 적어 두기만)
   - Region: **Northeast Asia (Seoul)**
   - 요금제가 **Free** 인지 확인 — 결제 화면이 나오면 진행하지 마세요
3. **Create new project** → 1~2분 기다리기

> 무료 프로젝트는 **한 계정에 2개까지**예요. 그리고 **7일 동안 아무도 안 쓰면 잠들어요**(방학 등).
> 그럴 땐 수파베이스 대시보드에서 프로젝트의 **Restore** 버튼을 누르면 데이터 그대로 다시 켜져요.

## 2단계. 표 만들기 (2분)
1. 이 저장소의 [`supabase/schema.sql`](../supabase/schema.sql) 을 열고 오른쪽 위 **복사 버튼(📋)** 으로 전부 복사해요.
2. 수파베이스 왼쪽 메뉴 **SQL Editor** → 빈 칸에 붙여 넣기 → 오른쪽 아래 **Run**
3. 아래에 **"Success. No rows returned"** 가 나오면 성공이에요. (표 9개가 생기고, 서버 말고는 아무도 못 읽게 잠겨요)

## 3단계. 주소와 비밀 키 복사 (2분)
왼쪽 아래 **⚙️ Project Settings**
- **Data API** (또는 위쪽 **Connect**) 에 있는 **Project URL** `https://xxxx.supabase.co` → **`SUPABASE_URL`**
- **API Keys → Secret keys → default** 의 복사 버튼 → `sb_secret_...` → **`SUPABASE_SECRET_KEY`**

⚠️ secret 키는 학생 데이터를 마음대로 볼 수 있는 열쇠예요. 카톡·메일·게시판·**AI 채팅**에 붙여 넣지 마세요.
4단계에서 Vercel 칸에 바로 붙여 넣는 게 가장 안전해요.

## 4단계. 배포 버튼 누르기 (5분)
1. 이 저장소의 README 에 있는 **[Deploy with Vercel]** 버튼을 눌러요.
2. **Continue with GitHub** 로 Vercel 에 가입/로그인 (무료 **Hobby** 요금제 — Pro·Trial 버튼은 누르지 마세요)
   - 2단계 인증(2FA) 안내가 뜨면: 원하면 설정, 아니면 **Remind Me Later**
3. 저장소 이름은 그대로 두고 **Create** → 이어서 **값 4개**를 넣는 칸이 나와요:
   - `SUPABASE_URL`, `SUPABASE_SECRET_KEY` → 3단계에서 복사한 값
   - `JWT_SECRET` → 영어·숫자를 **아무렇게나 40자 이상** 섞어서 (예: 키보드를 마구 두드리기). 아무에게도 알려 주지 마세요
   - `TEACHER_INIT_PASSWORD` → 처음 선생님 로그인에 쓸 비밀번호 (한 번만 써요)
4. **Deploy** → 1~2분 뒤 🎉 화면이 나오면 **Continue to Dashboard** → 위쪽 **Domains** 에 있는 `○○.vercel.app` 이 우리 반 주소예요.

## 5단계. 첫 로그인 (2분)
1. 우리 반 주소로 들어가서 학번 칸에 `teacher`, 비밀번호에 `TEACHER_INIT_PASSWORD` 를 넣어요.
2. 새 선생님 비밀번호로 바꾸면 **선생님 화면**이 나와요.
3. (선택) 안전을 위해 Vercel › 프로젝트 › **Settings › Environment Variables** 에서 `TEACHER_INIT_PASSWORD` 를 지워요.

## 6단계. 학생 등록 (5분)
1. 엑셀에서 `학번,이름` 두 칸으로 명단을 만들고 **CSV 로 저장** (첫 줄 제목은 있어도 괜찮아요)
2. 선생님 화면 › **CSV 파일 선택** → 등록 끝. 자리 번호는 학번 순서로 자동 배정돼요.
3. 학생들의 첫 비밀번호는 모두 **`000000`** 이에요.
   → **첫 로그인은 교실에서 다 같이** 하고, 그 자리에서 각자 비밀번호를 바꾸게 해 주세요.
   (선생님 화면에서 "아직 안 바꿈" 인 학생은 친구가 대신 들어갈 수 있어요)

## 7단계. 학생들 폰에 앱처럼 추가
- 아이폰(사파리): 아래 **공유 버튼 → 홈 화면에 추가**
- 삼성 인터넷: 아래 **☰ → 현재 페이지 추가 → 홈 화면**
- 크롬: 오른쪽 위 **⋮ → 홈 화면에 추가**

## 자주 막히는 곳
| 증상 | 해결 |
|---|---|
| 첫 로그인에서 "학번 또는 비밀번호가 맞지 않아요" | 학번 칸이 정확히 `teacher` 인지, 비밀번호가 `TEACHER_INIT_PASSWORD` 와 같은지 확인 |
| 첫 로그인에서 "잠시 문제가 생겼어요" | ① 2단계 SQL 을 실행했는지 ② `SUPABASE_URL` 이 `https://...supabase.co` 형태인지 ③ secret 키를 끝까지 복사했는지. 고친 뒤 Vercel › Deployments › 맨 위 › **Redeploy** |
| 방학 뒤에 갑자기 안 열려요 | 수파베이스 프로젝트가 잠든 거예요 → 대시보드에서 **Restore** |
| 값을 잘못 넣었어요 | Vercel › Settings › Environment Variables 에서 고치고 **Redeploy** |
| 비밀번호를 잊은 학생 | 선생님 화면 › 그 학생 **초기화** → 다시 `000000` |
| 선생님 비밀번호를 잊었어요 | 수파베이스 › **Table Editor › students** 에서 선생님 줄(role 이 `teacher` 인 줄)을 지우고, Vercel 에 `TEACHER_INIT_PASSWORD` 를 다시 넣고 Redeploy → 5단계 다시 |
| 학생 기록을 표로 보고 싶어요 | 선생님 화면 › **📥 이번 달 기록 CSV**, 또는 수파베이스 › **Table Editor** |

## 개인정보 안내
- 학생 데이터(학번·이름·공부 기록)는 **선생님의 수파베이스 프로젝트에만** 저장돼요(서울 지역). 다른 반·제작자에게 전달되지 않아요.
- 학교 개인정보 담당 선생님께 한 번 확인받고, 학부모 안내문에 "학번과 이름만 사용, 학급 학습관리용" 정도를 적어 두면 좋아요.
